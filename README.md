# Sales & Demand Forecasting using Machine Learning

## 📌 Project Overview

This project predicts future sales using historical business data. A Linear Regression model was built to forecast future sales and visualize sales trends. The project demonstrates how Machine Learning can support business planning and decision-making.

---

## 🎯 Objective

The objective of this project is to:

- Forecast future sales using historical sales data.
- Analyze sales trends over time.
- Help businesses make informed decisions using sales predictions.

---

## 🛠️ Tools & Technologies Used

- Python
- VS Code
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

---

## 📂 Dataset

**Dataset Used:** Superstore Sales Dataset

The dataset contains historical sales records, including order dates and sales values, which are used to build the forecasting model.

---

## ✨ Project Features

- Data cleaning and preprocessing
- Handling missing values
- Time-based feature engineering (Year, Month, Day)
- Daily sales trend analysis
- Sales forecasting using Linear Regression
- Model evaluation using:
  - MAE (Mean Absolute Error)
  - MSE (Mean Squared Error)
  - RMSE (Root Mean Squared Error)
  - R² Score
- Future Sales Forecast (Next 30 Days)
- Business-friendly visualizations

---

## 📊 Visualizations

The project includes:

- Daily Sales Trend
- Actual vs Predicted Sales
- Sales Forecast for the Next 30 Days

---

## 📈 Business Applications

This forecasting model can help businesses:

- Plan inventory effectively
- Reduce stock shortages and overstocking
- Estimate future revenue
- Manage cash flow
- Plan staffing based on expected demand
- Support data-driven business decisions

---

## 📋 Project Workflow

1. Import libraries
2. Load the dataset
3. Clean and preprocess data
4. Create time-based features
5. Visualize historical sales
6. Train the Linear Regression model
7. Evaluate model performance
8. Forecast future sales
9. Visualize forecast results

---

## 📌 Conclusion

A Linear Regression model was successfully developed to forecast future sales using historical sales data. The model provides useful business insights through visualizations and performance evaluation, demonstrating how machine learning can support business planning.
